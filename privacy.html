1. ขอบเขต

นโยบายนี้ใช้กับเว็บไซต์นี้ และโปรแกรม "ฎีกาบนกระดาน โพสต์" ซึ่งเป็นเครื่องมือส่วนตัวที่เจ้าของช่องฎีกาบนกระดานใช้อัปโหลดคลิปของช่องเองขึ้น YouTube, Facebook และ TikTok โปรแกรมนี้ใช้กับบัญชีของช่องเท่านั้น ไม่เปิดให้บุคคลอื่นเข้าสู่ระบบ

2. ข้อมูลที่โปรแกรมเข้าถึง

เมื่อเจ้าของช่องอนุญาตสิทธิ์ผ่านหน้าล็อกอินของแต่ละแพลตฟอร์ม โปรแกรมจะได้รับและใช้เฉพาะ:

  • โทเค็นสิทธิ์ (access/refresh token) ของบัญชีช่อง เพื่ออัปโหลดคลิปและตั้งเวลาเผยแพร่
  • ข้อมูลพื้นฐานของบัญชีช่อง เช่น ชื่อช่องและรหัสช่อง เพื่อยืนยันว่าอัปโหลดถูกบัญชี
  • สถานะและลิงก์ของคลิปที่ช่องอัปโหลดเอง เพื่อตรวจว่าเผยแพร่สำเร็จ

โปรแกรมไม่เก็บรหัสผ่าน และไม่เก็บข้อมูลของผู้ชมหรือผู้ใช้คนอื่น

3. การเก็บและใช้ข้อมูล

โทเค็นและบันทึกการโพสต์เก็บไว้ในคอมพิวเตอร์ของเจ้าของช่องเท่านั้น ไม่ส่งให้บุคคลที่สาม ไม่ขาย ไม่ใช้เพื่อโฆษณา และใช้เพียงเพื่ออัปโหลดและจัดการคลิปของช่องตามที่อธิบายไว้ข้างต้น

4. บริการ YouTube API

โปรแกรมใช้ YouTube API Services การใช้งานอยู่ภายใต้ ข้อกำหนดในการให้บริการของ YouTube และ นโยบายความเป็นส่วนตัวของ Google

5. การยกเลิกสิทธิ์และลบข้อมูล

ยกเลิกสิทธิ์ของโปรแกรมได้ทุกเมื่อที่ หน้าสิทธิ์การเข้าถึงของบัญชี Google, การตั้งค่าแอปที่เชื่อมต่อของ Facebook และ TikTok เมื่อยกเลิกแล้ว เจ้าของช่องลบไฟล์โทเค็นออกจากเครื่องได้ทันที

6. เว็บไซต์นี้

เว็บไซต์นี้เป็นหน้าเว็บนิ่ง ไม่ใช้คุกกี้ ไม่มีระบบติดตามหรือวิเคราะห์ผู้เข้าชม และไม่มีแบบฟอร์มเก็บข้อมูล ผู้ให้บริการโฮสต์ (GitHub Pages) อาจบันทึกข้อมูลทางเทคนิคตาม นโยบายของ GitHub

Privacy Policy (English)

Scope. This policy covers this website and "ฎีกาบนกระดาน โพสต์", a private desktop tool used only by the owner of the Dika on Board channel to upload the channel's own videos to its own YouTube, Facebook and TikTok accounts. No other users can sign in to the tool.

Data accessed. After the owner grants permission through each platform's sign-in page, the tool uses only: OAuth access/refresh tokens for the channel account (to upload and schedule videos); basic channel information such as channel name and ID (to confirm the correct account); and the status and links of videos the channel itself uploaded. The tool does not store passwords and does not collect data about viewers or any other users.

Storage and use. Tokens and posting records are stored only on the channel owner's computer. They are not shared with third parties, not sold, not used for advertising, and used only for uploading and managing the channel's videos.

YouTube API Services. The tool uses YouTube API Services. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access. Access can be revoked at any time via Google Account permissions and the connected-apps settings of Facebook and TikTok; the owner can then delete the stored tokens.

This website is static, uses no cookies, analytics or tracking, and has no data-collection forms. The host (GitHub Pages) may log technical data under GitHub's privacy statement.
